# POL-DOC-01 - Document Management and File Naming
## 1. Matter Folders
Every matter folder follows this structure: 01_Instructions, 02_Correspondence, 03_Filings, 04_Official_Documents, 05_Billing.

## 2. File Naming Convention
Format: **MatterNumber_DocType_YYYYMMDD_vN** (for example LIP-2026-00412_ResponseDraft_20260915_v2).
- Document type codes include: POA, FilingReceipt, OfficeAction, ResponseDraft, Certificate, Invoice.
- Drafts keep their version number; the filed version is marked **_FINAL**.

## 3. Official Documents
Official documents received from DJKI must be uploaded to the matter folder and entered in the docketing system on the **same working day**.

## 4. Email Filing
Client emails relating to instructions must be filed to the matter folder within **2 working days**.
