# SOP-TM-01 - Trademark Search and Clearance
## 1. Purpose
This SOP sets out how Lumina IP Partners runs a pre-filing trademark search and issues a clearance opinion before any new application is filed.

## 2. Search Types
- **Knock-out search**: identical and near-identical marks only, in the requested classes. Delivered within **1 working day**. Fee: **IDR 750,000 per class**.
- **Comprehensive search**: identical, phonetic, visual and conceptual similarity, including related classes and pending applications in the DJKI database. Delivered within **3 working days**. Fee: **IDR 2,000,000 per class**.
- **Device (logo) search**: added to a comprehensive search when the mark contains a figurative element, using Vienna classification codes. Surcharge: **IDR 1,000,000 per class**.

## 3. Procedure
1. The associate confirms the exact mark, the goods/services and the Nice classes with the client.
2. The paralegal runs the search on the DJKI public database and the firm's internal watch database.
3. Each conflicting mark is rated **Low, Medium or High risk** using the Similarity Matrix (Annex A).
4. A senior associate reviews every High-risk finding before the opinion is sent.
5. The clearance opinion is issued on the standard template (TMPL-TM-SRCH) and saved in the matter folder.

## 4. Rules
- A clearance opinion is valid for **30 calendar days**. After that the search must be refreshed before filing.
- The firm never guarantees registration. Every opinion must include the standard disclaimer paragraph.
- If two or more High-risk conflicts are found, the associate must recommend either re-branding or a co-existence strategy.
